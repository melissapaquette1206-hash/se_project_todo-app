# Simple Todo App

This Todo App is a responsive task management application that allows users to create, view, and delete daily tasks. The project focuses on applying JavaScript fundamentals, DOM manipulation, and form validation to build an interactive and user-friendly web app.

## Functionality

Add new tasks using a form input

Prevent empty or invalid submissions through form validation

Display tasks dynamically on the page

Delete individual tasks when they are no longer needed

Interact with a clean, responsive interface that updates in real time

## Technology

This project was built using the following technologies and techniques:

HTML5

Semantic markup for structure and accessibility

CSS3

Flexbox for layout

Responsive styling for different screen sizes

JavaScript (ES6)

DOM manipulation

Event handling

Form validation

Modular, reusable functions
